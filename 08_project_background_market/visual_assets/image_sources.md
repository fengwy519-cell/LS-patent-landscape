# 图片与可视化素材来源清单

适用范围：`08_project_background_market/` 三页 PPT 的全部图像素材。基准版本 `BACKGROUND-MARKET-CONTENT-FROZEN-v1`，整理日期 2026-09-14。

## 一、结论：本轮全部素材为自绘，未使用任何第三方图片

**三页 PPT 中没有直接嵌入任何来自论文、厂商网页或技术文档的图片、原理图、产品照片或 Logo。** 全部 11 个 SVG 均由 [`src/generate_background_market_visuals.mjs`](src/generate_background_market_visuals.mjs) 以代码生成，可完整复现。

这一选择是按任务给定的优先顺序逐级判断的结果，下一节说明为什么没有停在第 1 级。

## 二、按优先顺序的取舍过程

### 第 1 级｜直接使用已有高质量图片 —— 未采用

两个独立原因：

1. **本会话无法获取原图。** 环境网络策略拒绝了目标站点：对 `www.asml.com` 与 `global.canon` 的 HTTPS 请求均由代理返回 `403 CONNECT tunnel failed（policy denial）`。因此无法核验任何候选图片的分辨率、水印状态与实际内容——而"不使用低清、水印严重或版权来源不明的图片"要求必须先看到原图才能判断。
2. **即使可获取，版权边界也不适合。** S03–S08 全部是厂商官方产品与技术页面，页面图片为厂商版权素材，未取得授权；把它们嵌入对外可见的立项汇报材料并提交进仓库，风险高于收益。厂商 Logo 同样未使用，避免暗示合作或供应关系。

### 第 2 级｜参考已有资料的结构重绘 —— **本轮采用**

`01_ls_function_chain.svg` 的功能链与斜入射测高原理，结构依据项目既有研究与厂商公开的功能性描述重绘，不复制任何具体图形：

| 结构要素 | 依据 | 边界 |
|---|---|---|
| 五步功能链（光学测高 → 高度解算 → 面形重建 → 调焦调平 → 曝光控制） | `ls_background.md` §2 功能环节表 [S09] | 功能归纳，不是任何一款整机的信号流程图 |
| 斜入射投影 / 反射 / 接收的三段光路 | `ls_background.md` §2「主流反射式光学测高的功能概括」[S09] | 抽象示意；不同系统不一定同时检测位置、相位与强度 |
| Δh → Δx 的几何关系 | 同上；斜入射三角测量的通用几何 | 图中角度、比例为示意，未标注任何数值 |
| 晶圆翘曲 + 膜层双层结构 | `ls_background.md` §4；ASML DUV 产品页对晶圆翘曲与高起伏膜层的设备背景描述 [S04] | 示意性剖面，非真实晶圆几何或膜厚比例 |
| 三路辅助输入（标定/工艺补偿、平台坐标·采样时刻、最佳焦面基准） | `ls_background.md` §2 表与建议图主链 [S09] | —— |

其余四份素材（约束收敛、需求链、参与者生态、数字锚点）为信息组织图，不存在可参照的原始图形，其**内容**来源见下表。

### 第 3 级｜自主生成全新示意图 —— 用于第 2 级无对应原图的部分

风格限定为半导体装备 / 光学工程技术示意：白底、平面矢量、工程标注（尺寸线、引出线、虚线参考面），不做营销插画、卡通、渐变、发光或 3D。

图上出现的每一个数字，都能回到 `market_data.csv` 的一行与 `sources.md` 的一个编号：

| 图上数字 | CSV `data_id` | 来源 | 图内必须同时出现的边界 |

## 五、使用约束

- SVG 使用标准文本与基本矢量图形，未嵌入字体文件；字体栈为 `Noto Sans CJK SC / Source Han Sans SC / Microsoft YaHei / PingFang SC / WenQuanYi Zen Hei / sans-serif`，在未装中文字体的环境中需先安装其一。
- 未使用任何厂商 Logo、产品照片或商标图形。
- `01` 是功能示意，不是任何具体光刻机的真实机械布局或尺寸。
- `02` 是约束关系图，不代表五项技术路线均已选型。
- `03` 表示需求传导，不是固定比例换算模型。
- `04` 只表达公开可确认的角色分类，不表达市场份额，也不表达已确认的供应关系。
- `05` 的两组数字口径不同，不相加、不共用坐标轴。
- 若后续要替换为厂商原图，必须先取得授权，并在本文件登记原始出处、许可方式与获取日期。

## 六、复现方式

```bash
cd 08_project_background_market/visual_assets/src
node generate_background_market_visuals.mjs      # 重新生成全部 SVG
```

PNG 预览由无头 Chromium 以 2× 缩放渲染同名 SVG 得到，不参与正式 PPT 组装。
