## 设计约束

- SVG 使用标准文本和基本矢量图形，可在 PowerPoint / Illustrator 等软件继续编辑。
- 字体采用通用中文无衬线字体栈：`Noto Sans CJK SC / Microsoft YaHei / PingFang SC / Arial / sans-serif`；未嵌入任何字体文件。
- 颜色以蓝、蓝绿色和中性灰为主；黄色只用于“边界/提醒”，不用于制造趋势结论。
- 未使用厂商 Logo，避免制造合作或供应关系暗示。
- 所有市场数值只来自冻结版本 `market_data.csv`；`05_market_data_anchor.svg` 最终只展示 M1、M2，主动删除 M3 以控制页面密度与误读风险。

## 使用边界

- `01` 是功能示意，不是任何具体光刻机的真实机械布局。
- `02` 是约束关系图，不代表五项技术路线均已选型。
- `03` 表示需求传导，不是固定比例换算模型。
- `04` 只表达公开可确认的角色分类，不表达市场份额或具体供应链。
- `05` 中 380→300 不表示行业下滑；405.3 亿美元为全球全部半导体设备 2026 Q2 billings，不是光刻或 LS 市场规模。
