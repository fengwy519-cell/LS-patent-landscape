## 背景第 1 页｜LS 把晶圆表面高度转化为曝光补偿

**唯一问题：LS 是什么，怎样服务曝光？**

建议保留三句话：

- LS 测量晶圆表面的高度和倾斜，为调焦调平提供输入。
- 光学测高 → 表面图重建 → 平台 Z / Rx / Ry 补偿 → 控制曝光离焦。
- 几何高度须通过焦面基准和工艺标定，才能转成正确曝光控制量。[S09]

建议可视化结构（供下一阶段制作）：

- 主体约 2/3：功能链。第一框内部用“斜入射投影—晶圆反射—接收信号”三个小环节说明原理，其后接高度解算、表面图、平台补偿。
- 在高度解算下方接“标定/膜层补偿”，在表面图下方接“平台坐标/时间”，在控制框下方接“最佳焦面基准”。连接线不得暗示 LS 自己移动平台。
- 侧边小注：对准看平面位置；LS 看高度；套刻看层间图形误差。[S03,S09]
- 不按具体机型画安装尺寸；标明“功能示意，测量可预先或并行进行”。

讲解补充：调焦调平系统大于 LS 光学头；控制目标是满足允许离焦范围，不能写“所有位置始终完美合焦”。

## 背景第 2 页｜难点是高速、复杂工艺下持续输出可信高度图

**唯一问题：为什么普通测距能力不足以支撑光刻？**

建议 2×3 矩阵，每格只保留“原因 → 能力需求”：

1. 晶圆不平 → 多点测量与表面重建。
2. 膜层复杂 → 抑制表观高度偏差。
3. 起伏范围大 → 精度与捕获范围兼顾。
4. 曝光节拍快 → 分辨率、光子数与速度平衡。
5. 长期连续运行 → 通道一致性、漂移监测与标定。
6. 平台高速运动 → 同步采样与可靠控制。[S04,S06,S07,S09]

下方可选一个量化锚点：Canon 公开整机生产率 >200 片/小时（300 mm、98 shots、配置选件）。注明“整机节拍示例，不是 LS 采样速度或本项目指标”。[S06]

主结论：单点精度只是起点，可用于曝光的稳定高度图才是系统交付物。UV 不单独展开；口头说明它是降低下层反射影响的一条路线，仍有光预算和集成代价。

## 市场第 1 页｜需求随整机产生，价值取决于系统准入

**唯一问题：市场为什么存在、谁在做、为什么进入门槛高？**

建议采用三个区域，避免堆叠成仪表盘：

- 左侧：制造需求 → 晶圆厂投资 → 光刻设备 → LS 配套需求。箭头标注“需求传导，非固定比例”。
- 中部：ASML 新机销量两根柱（2024：380；2025：300 台）。旁边一句反证：“同期公司收入增长，金额不等于台数”。可再放一条全球设备景气注释：“2026Q2：405.3 亿美元，同比 +23%”，必须标“全部半导体设备”。[S01,S02]
- 右侧：整机与集成：ASML / Nikon / Canon / SMEE；上游光学：ZEISS；国内研究：中科院相关机构等。下接三项壁垒：“工艺适应”“稳定标定”“平台控制与整机验证”。[S04–S09]

页底必要表述：**公开资料未单列可核验 LS 市场，采用整机和设备投资指标代理；不据此估算 LS TAM。**

此页不使用专利数量作为市场份额，不比较不同测试条件下的整机生产率。若版面不足，优先删除全球设备金额注释，保留市场链、销量、参与者与壁垒。
