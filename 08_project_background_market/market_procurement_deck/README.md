## 内容与风险映射

市场页只采用M1与M2：380/300台；405.3亿美元与同比23%。M1为单厂商销量，M2为全球全部半导体设备单季billings，均非LS规模；不展示M3。参与者按国际整机、国内整机、上游、研究分层；ASML的EUV能力不赋予其他厂商，不画供货连线。

采购五类是功能归并而非全选BOM。UV照明高风险针对高亮度分支，氘灯系统中风险保留在脚注；UV探测/电子学为通用中、阵列高；最后一类为光纤中、关键定制高。均来自component_risk_matrix.md，未重评风险。供应商均为候选，国内阵列只为技术候选。
