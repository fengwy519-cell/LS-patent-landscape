# LS 关键元器件与采购风险

2026-09-14｜采购技术预筛，不是定点供应商名录。补充原市场分析，原 `BACKGROUND-MARKET-CONTENT-FROZEN-v1` 数据与图稿不变。配套：[统一风险矩阵及汇报文案](component_risk_matrix.md)、[供应商证据](component_sources.md)。

**结论：优先前置 UV/DUV 光源适配、精密光学件加工—镀膜—检测闭环、定制光栅验证。风险主要来自要求组合与换源验证成本，不能仅按供应商数量判断。** 这些是工程预判；尚无本项目询价单、合同交期或合格供应商记录，不宣称已确认单一来源或国产能力不足。

## 1. 功能 BOM 与当前边界

现有资料支持“照明 → 投影 → 晶圆反射 → 接收/分光 → 探测 → 高度解算”的功能 BOM，没有完整采购 BOM、最新图纸及器件级误差预算。本报告因此不擅自指定工作波段、功率、面形公差、光栅周期或 ADC 型号。项目既有多点/多通道路线需要一致性；阵列直采是可选架构，不与光电二极管方案强行同时列装。

询价先明确：工作波段与有效带宽、各通道探测面最低光功率、噪声频段与允许漂移、有效口径和入射角、光栅版图及位置/相位公差、安装基准、检测方法、首件/批次数量。这些决定候选是否真正可替代。

## 2. 光源：买得到发光器件，不等于获得可用照明

| 路线与候选 | 官方证据 | LS 匹配与采购判断 |
|---|---|---|
| 宽谱高亮度：Energetiq EQ-99X / EQ-99XFC | 官方披露小展度高亮度宽谱路线及光纤输出版本 [C01] | 商用品可作评估；实际波段、光纤版本与出射光谱需锁定，不把自由空间覆盖范围照搬到光纤端。换成另一类光源可能需重做耦合和光预算；高风险是平台依赖，未证实市场唯一供应商 |
| 氘灯：Hamamatsu L2D2；Excelitas Noblelight；Thorlabs SLS204 | 分别有UV氘灯/稳定光源产品；SLS204标称200–700 nm、灯泡寿命2000 h [C02–C04] | 有成熟商用品与替换灯泡；不能用灯的电功率替代有效波段辐射功率。亮度、弧点漂移、预热、热管理和照明面积共同决定适配 |
| 国内系统：卓立汉光 LSH-D30 / LSP-D30 | 200–400 nm，页面给出光通波动≤0.5%、平均灯泡寿命2000 h [C05] | 国内可采购系统候选；波动测试带宽/时长未完整给出，不能直接用于LS噪声预算。灯泡与核心材料原产地未确认，不能称全国产 |
| 窄带UV LED：Stanley ZEUBE265-2CA | 265 nm、50 mW、440 mA条件；是器件辐射通量 [C06] | 商用品，但不是宽谱LS直接替代。须验证带宽、温漂、出射角、耦合后功率与膜层适应。国内同规格全套资格证据本轮不足 |

**采购应比较的是探测端有效信号。** 光谱功率密度与收光展度决定能耦合多少光；总辐射功率不能保证每个测点的信噪比。均匀性还依赖匀光/投影系统，不能要求灯单独保证晶圆面均匀性。短时噪声、长时漂移、换灯后复现性须分开验收。

低相干宽谱、窄带LED和相干激光并非等效路线。若采用激光，还需评估散斑、脉冲同步及剂量；本轮不因“有266 nm激光”就列为可替换LS光源。UV/DUV 选型必须给出实际纳米范围，不能只写“紫外”。

价格与交期：未获可比较报价。成本拆为光源、控制/冷却、耦合/匀光、替换灯泡、重新标定与停机；请厂商分别报价首件、复购、耗材和维修周转。研发排期前置光源借样，不给未经证实的周数。

## 3. 光学与光机：主要难在组合公差与闭环制造

| 环节 | 候选及能力证据 | 对 LS 的匹配边界 |
|---|---|---|
| UV材料 | Corning HPFS，Heraeus Suprasil [C07,C08] | 有UV/DUV材料路线；必须指定牌号、厚度下透过率、均匀性、双折射和照射稳定性，不能把任意“石英”当等效。国内同等级原料批次能力未核实 |
| 精密面形加工 | ZYGO 定制球面/非球面/自由曲面；国内福晶 CASTECH 精密光学 [C09,C10] | 是加工候选证据，不是对本项目口径、离轴量与全公差的承诺；国内离轴件综合能力需技术评审和首件证明 |
| 镀膜 | CASTECH 镀膜中心；Edmund OEM定制镀膜 [C10,C11] | 应指定整个波段、角度范围和两偏振的反/透射及相位要求；不能以单波长高反或激光损伤阈值替代宽谱测量性能 |
| 装配/稳定性 | 定制镜座、低应力固定和基准传递需与光学供应商联合确认 | 标准调整架可用于台架，不自动满足装机漂移、空间和洁净要求；本轮未确认合格量产装配供应商 |

风险不宜归因于“抛不出好面形”这一项。应按 **原料 → 加工 → 镀膜 → 装配 → 工作波段验证**管理：

- 面形需写清有效口径、空间频率、去除项、检测波长及单位；表面质量、粗糙度与面形是不同指标。
- 离轴元件须明确母面、截取位置和机械基准。偏心/倾斜、厚度/楔角与检测坐标统一，否则独立尺寸合格也可能装不起来。
- 镀膜应比较镀前/镀后面形和偏振特性。见证片能验证膜系的一部分，不能代替实件全口径性能。
- 装配胶/夹紧应力、温度循环与清洗会影响稳定性。首件合格不证明稳定批量；要保留批次统计和复测基准。

**综合判断：** 常规窗口/平面镜有商业基础；高精度离轴件加宽谱UV膜层属于高风险定制组合。长周期来自加工、检验和返工串行叠加，是潜在排程风险，实际周期待图纸报价确认。

## 4. 光栅：多区域精度与使用状态验收比最小线宽更关键

先区分：投影/检测振幅光栅用于图案调制；刻蚀相位光栅依赖深度与材料色散；光谱仪分光光栅不能凭“线数相同”直接替换。多区域“相位”也需区分版图横向错位与材料光程相位。

| 工艺路线 | 适用结构 | 核心验证与局限 |
|---|---|---|
| 激光直写/电子束写入 → 显影 → 铬等金属膜刻蚀 | 多区域、不同占空比的振幅图案 | 线宽、周期累计误差、边缘粗糙度、区域坐标、膜层遮光/反射及针孔；电子束更细不代表大面积更准或更快 |
| 光刻转移 → 反应离子刻蚀 | 石英等基底上的相位/浮雕结构 | 深度、侧壁、全区域均匀性；相位随波长及入射条件变化，需工作带宽验证 |
| 母版 → 复制/压印 | 有批量复制价值的微结构 | 母版误差传递、收缩和缺陷重复；复制材料的UV耐久与污染须验证，不能直接替代无机刻蚀件 |

工艺依据供应商母版加工说明、炬光光刻/RIE平台及深圳技术大学公开制版流程。[C12–C15]

候选：APPLIED IMAGE/Microtronics 提供定制掩模；Holographix提供母版工艺协调和复制光学，不应被当成所有工序均内部完成；国内清溢有掩模产业能力、炬光有光刻/RIE微纳平台，均需确认是否承接小批LS功能光栅及对应验收。深圳技术大学平台可作为试制路线，官方默认钠钙玻璃铬版，石英需另行沟通，不是已确认DUV量产供应商。[C12–C16]

**光栅可能成为最关键的长周期定制件之一（工程判断）。** 多区域位置和占空比误差会改变通道响应；缺陷、反射杂光和局部相位误差不能靠中心线宽检查覆盖。若检测光栅与探测器贴合，还叠加装配相位、胶层和返修风险。更换供应商通常需重测通道相位、灵敏度与零位，不能仅比较版图文件。

建议验收交付：全幅坐标/周期误差图、各区域线宽/占空比统计、缺陷图、基片面形、工作波段反透射，以及成对投影/检测状态的调制与通道一致性。先做包含关键区域的工艺样片，再制作全尺寸首件；保存母版/写入文件和制造版本，避免因数据或母版归属造成事实锁定。

## 5. 探测器与电子学：商用品较多，替代仍需重验

- **分立探测器：** Hamamatsu S1227-16BQ标称190–1000 nm；其0.36 A/W典型值对应峰值条件，不能当UV全波段响应。sglux有SiC UV探测器，但普通系列在约200 nm以下响应不足，短波专用品须另选。[C17,C18] 对暗电流、结电容、响应速度和有效面积联合选型，不能只看响应范围。
- **线阵/面阵：** Hamamatsu S13256系列是背照线阵候选；国内Gpixel有BSI/PulSar技术公开证据，但所引新闻是2020年技术/样片说明，不能证明今天特定DUV型号现货。标准GSENSE封装/窗口也不等于UV专用品。[C19,C20] 必须核查量子效率、窗口、满阱、读噪、快门与实际有效行率，保留坏点与像元校正。
- **ADC/模拟前端：** TI ADS127L18为8通道24位同步采样，ADI AD7606C-18为8通道18位同步采样，属于不同滤波/接口架构的候选，不是引脚兼容替代。[C21,C22] 标称位数不等于有效精度；跨片同步、前端跨阻噪声、参考源漂移和滤波延迟影响最终高度信号。最终高度输出率不等于原始调制采样率。
- **FPGA/采集：** 尚无本项目确定芯片、速率或接口，不指定型号与国产替代结论。主要风险是封装/接口、时序与工具链锁定；需在定型时核实生命周期、变更通知、授权供货及迁移代价。未获得停产/断供证据，不写“必然受限”。

分立PD+通用同步采样电子学综合预筛为中；特定UV阵列及定制封装为高。国内可替换的精确型号、原产链和批次噪声表现仍需确认，不用代理商中文页面当国产证明。

## 6. 其他只保留关键件

**分光/偏振/滤光：** 福晶有多类分光与镀膜能力；其通用激光PBS页列BK7及可见/近红外标准波长，不能拿该页表格宣称DUV适配。[C23] 需对目标波段重新指定材料、胶层/光胶、角度、消光比、波前和偏振相位。分光模块直接影响信号传输、通道一致性与高度解算，属于高风险定制件。

**光纤耦合：** Thorlabs有180–1200 nm抗紫外致暗多模光纤/跳线产品，但这是产品范围而非保证任意长度与剂量下损耗恒定。[C24] 需测工作波段插损、弯曲、端面污染、老化及换装重复性；若用于偏振测量，普通多模光纤不能被默认保持偏振。

**精密调节件：** 只在承担光学基准、主动校准或锁紧后稳定性时纳入关键件；本轮无具体机构图，不列未经匹配的台型。要求给出锁紧位移、迟滞、漂移与整机安装后的测校方式。

## 7. 采购动作：减少一次失败造成的串行等待

优先执行三项：光源带真实耦合负载借样；光学件镀前/镀后与安装基准联合评审；光栅关键区域工艺样片。向候选同时索取首件/复购交期、报价拆分、检测原始数据与不合格返工周期，不先下批量单。

对换源必须重标定的件，提前保留接口与校准数据；按器件验证可替代性，而非简单建“两家名单”。未获资格证明前，国内可得性只写“候选可询价/待验证”。本轮未向供应商发出消息或询价。
