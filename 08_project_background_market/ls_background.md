# LS 项目背景：从表面测高到曝光焦面控制

状态：**BACKGROUND-MARKET-CONTENT-FROZEN-v1**。适用：立项背景第 1–2 页。证据截止 2026-09-11；来源编号见 [sources.md](sources.md)。本文为产品与物理问题归纳，不新增专利分析。所有公开指标均不是本项目验收指标。

## 1. 一句话定义

**Level Sensor（LS，晶圆测高传感器）测量晶圆表面高度及倾斜，为光刻机调焦调平控制提供输入。** 调焦调平系统的范围还包括基准、表面图重建、平台与控制器，不能把整个系统等同于一个光学头。[S09]

曝光有有限的允许离焦范围。晶圆装夹后的翘曲、膜层厚度变化和局部起伏，会使待曝光表面偏离目标焦面；测高信息帮助平台在曝光时校正高度 Z 和绕水平轴的倾角 Rx、Ry。单靠机械装平不能充分描述整片晶圆的局部高度。[S04,S07,S09]

## 2. 位于哪里、怎样工作

LS 的测量光路面向晶圆，通常与曝光光路分开布置，并通过共同位置/高度基准关联。具体设备可预扫描测量，也可将测量与曝光工位并行安排；不能一概画成“曝光光束旁边始终实时测高”。这里采用功能框图，不声称复原某款整机的物理布局。[S09]

| 功能环节 | 输入与处理 | 输出 |
|---|---|---|
| 光学投射 | 以斜角将光斑、狭缝或光栅图案投到晶圆 | 表面反射光 |
| 光电检测 | 高度变化使接收图案的位置、相位或经调制的强度变化 | 多点原始测量信号 |
| 标定与解算 | 结合灵敏度、零位及工艺补偿；强度变化本身不等于高度变化 | 各测点 Z 及有效性信息 |
| 表面图重建 | 联合平台 X/Y 坐标、采样时刻与参考基准，拟合/拼接 | 晶圆表面高度图及局部倾斜 |
| 曝光控制 | 对应曝光区域及允许控制带宽，生成平台轨迹 | Z / Rx / Ry 调焦调平补偿 |

上述是主流反射式光学测高的功能概括；不同系统不一定同时检测位置、相位和强度。[S09]

**建议图的主链：光学测高 → 高度解算 → 晶圆面形重建 → 平台调焦调平 → 控制曝光离焦。** 在“高度解算”和“曝光控制”下方各接一个小输入框：“标定/工艺补偿”“最佳焦面基准”。LS 测到的表面几何高度，必须经基准与工艺关系校准才能服务曝光；LS 不单独确定光学最佳焦面。[S09]

控制目标是使残余离焦满足工艺窗口，不是保证每一处表面永久、精确位于同一焦平面。平台刚体 Z/倾角运动不能消除任意高空间频率起伏。

## 3. 与其他功能的区别

| 功能 | 核心问题 | 与 LS 的关系 |
|---|---|---|
| 普通自动对焦 | 常以图像清晰度寻找焦点，也存在主动测距方式 | LS 面向扫描曝光的多点高度与平台控制，不能照搬相机对焦模型 |
| 对准 | 晶圆标记与版图在平面内的位置、旋转等 | 提供平面坐标关联，不是晶圆表面测高 |
| 套刻 | 不同图形层之间的相对位置误差 | 是图形成像后的关键质量指标，不是 LS 测量精度 |
| 曝光后焦点计量 | 从已形成图形推断焦点/工艺表现 | 可反馈优化曝光，与曝光前几何测高互补 |

边界依据设备计量说明及既有项目研究。[S03,S09]

## 4. 六个系统问题：为什么难

| 立项逻辑 | 物理/产品原因 | 需要的能力 |
|---|---|---|
| 晶圆不平，必须测全、测准 | 翘曲、局部台阶与边缘可能同时出现，单点不能代表曝光区 | 多点采样、边缘有效性判断、表面图重建 |
| 膜层复杂，必须测得可信 | 表面与下层反射混合，随膜厚/材料改变而出现“表观高度”偏差 | 波段/偏振选择、工艺补偿；短波增强表面选择性是一种办法 |
| 起伏范围大，必须兼顾精测与捕获 | 高灵敏度信号可能量程有限或周期多解 | 粗精结合、量程切换及交叉标定 |
| 曝光节拍快，必须兼顾分辨率与光子数 | 小测量区域采光减少；增加采样又消耗时间 | 多点并行、合理光预算与采样策略 |
| 长期运行，必须稳定且可标定 | 通道增益/相位/零位差异叠加温漂、光路漂移 | 共同基准、通道校准、漂移监测 |
| 高速运动，数据必须可用于控制 | 振动、延迟、坐标和时钟误差会把好测量变成错误补偿 | 时间同步、动态误差预算、平台轨迹协同 |

前四项是测量有效性的条件；后两项决定长期设备可用性。依据既有难点归纳与厂商对翘曲、调焦调平、扫描同步的公开描述，不代表本项目选定实现方案。[S04,S06,S07,S09]

## 5. 只选有条件的公开数字

- Canon FPA-6300ES6a：300 mm 晶圆、每片 98 个曝光场、配置选件时，整机生产率 >200 片/小时。[S06]
- Nikon NSR-S636E：每片 96 个曝光场 条件下 ≥280 片/小时。[S05]
- 两者只说明测量必须适应高节拍；条件不同，不作厂商性能排名，也不把整机生产率当作 LS 采样速度。

当前不设置统一“行业 LS 纳米精度”、扫描速度或焦深数值。相关数值必须绑定波段、数值孔径、工艺、测量定义和测试条件；本项目指标尚未提供。PPT 建议只保留 Canon 一项带条件的节拍例子，其他作为备查。
