# 核心技术难点、演进与趋势：PPT 极简版

## 六个一级技术矛盾

| 一级矛盾 | 为什么难 | 专利中反复出现的解法 | 仍需权衡 |
|---|---|---|---|
| **1. Process dependency** | 光刻胶和多层膜产生表面/亚表面混合反射；膜厚、材料、波长、偏振和入射角变化会转化为 apparent height error | 宽谱平均、多波长×偏振补偿、非对称共轭、UV/DUV 表面选择性 | 模型依赖与 recipe 管理；短波又引入剂量、材料和低光子效率问题 |
| **2. Resolution / SNR / Throughput** | 小 footprint 提高横向分辨率却减少光子数；整片高密度 map 又受测量点数和 stage 节拍限制 | 多点/线扫/阵列、直接数字采样、邻场测量、大检测视场 | 分辨率、信噪比、光学视场和吞吐不能同时无限提高 |
| **3. Sensitivity / Dynamic Range** | 纳米级斜率/相位灵敏度容易在大翘曲、edge、沟槽和捕获阶段超量程 | capture beam、粗/精双支路、可变 NA/footprint、参考高度或检测段切换 | 切换迟滞、跨量程一致性和边缘异常 |
| **4. Multichannel Consistency / Calibration** | 多点、多波长、多偏振和阵列会带来 gain、phase、zero、几何位置和热漂移不一致 | 参考通道、归一化标记、主动光栅/元件校准、单体化光学、在线自检 | 标定可追溯性、重标周期、参考本身漂移 |
| **5. Environment / Stage Dynamics** | 空气折射率、热漂移、振动、扫描运动和时间同步把静态误差变成动态误差 | 共路/差分、温压补偿、运动件监测、同步采样、按高度时序限制 stage drive | 动态带宽、延迟、振动耦合和控制稳定性 |
| **6. Wafer Map System Integration** | 单点 Z 值必须转化为曝光系统可消费的高密度、低延迟且带可信度的 surface map | 预扫描/逐场扫描、拟合与异常剔除、不同 footprint 传感融合、按 shot 自适应布点 | map 空间盲区、模型偏差、传感器坐标/时间对齐及异常处理 |

## 五阶段演进主线

> 阶段相互重叠，不表示后一阶段完全替代前一阶段。

1. **2006–2009：基础测高走向可用。** 斜入射光斑/光栅、远心与反射式光路成熟，同时补齐捕获、粗精量程和多点覆盖。
2. **2009–2013：从几何测高转向 process-aware。** 光谱、偏振、反射率和膜栈模型进入补偿链；UVLS 以短波吸收从源头提高表面选择性。
3. **2011–2018：覆盖能力与量程扩展。** 多点、线扫、阵列、动态量程、边缘扫描和预扫描 map 共同解决分辨率—速度—范围矛盾。
4. **2016–2021：检测数字化与可校准集成。** detector array 直采、数字相位/莫尔解调、空间差分、主动标定和单体多通道减少机械件与通道漂移。
5. **2021–2024：wafer map 与曝光节拍协同。** 不同 footprint 融合、map correction、自适应布点、大检测区域、邻场测量和 relay/field splitting 面向更高吞吐和整机集成。

## UVLS：PPT 只讲三件事

- **为什么出现：**传统可见/近红外 LS 会穿透光刻胶并接收下层膜系反射，干涉后产生 process-dependent apparent height。
- **核心价值：**光刻胶敏感短波通常具有更强吸收，减少亚表面反射权重，提高最上表面选择性；代表性 claim 锚点为 [US8842293B2](https://patents.google.com/patent/US8842293B2/en)。
- **代价：**光源/探测效率、UV 透过材料与镀膜、污染、散射/杂散光、剂量预算和系统集成更困难。**UVLS 是 process dependency 的一条重要路线，不是 LS 的全部演进。**

## 趋势证据分级

### 已明确发生（多个 family 或连续路线支持）

- 从单一几何 Z 信号转向光谱、偏振、反射率或短波表面选择性的 process-aware 测量。
- 从少量离散点转向多点、线扫、阵列与数字解调。
- 从离线/一次性标定转向参考通道、运动件监测、主动校准和单体化多通道。
- 从独立传感器输出转向预扫描、wafer map、曝光控制和 stage 协同。

### 当前重点（最近 5–10 年公开样本明显出现）

- 多通道小型化、detector-array 直采和数字相位/莫尔处理。
- 动态量程、可变 footprint 及不同传感器/分辨率数据融合。
- 大视场、邻场/并行测量、field splitting/relay 与高吞吐 wafer map。
- 在线校准、map correction、自适应测点分配和扫描动态约束。

### 潜在方向（合理推测，尚未形成充分连续证据）

- **推测 1：**以 process recipe 驱动的波长/偏振/剂量自适应选择，将物理抑制与模型补偿组合。
- **推测 2：**带不确定度输出的物理模型 + 数据驱动残差校正，用于动态布点和异常 map 识别。
